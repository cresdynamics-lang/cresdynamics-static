Infrastructure

Client systems run on hardened hosts with firewalls, TLS 1.3, and regular security reviews. We monitor availability and patch critical paths promptly.

Access control

Role-based access across platforms. Admin paths require MFA where available. Privileged actions are logged for audit.

Encryption

Sensitive data encrypted at rest (AES-256) and in transit (TLS 1.3). Passwords hashed with bcrypt. Secrets live in environment config, never in source.

Backup & recovery

Daily encrypted backups with multi-week retention. Documented recovery procedures targeting restore within hours of a critical failure.

Your data

You own it. We use client data only to deliver agreed services. On request after project close and settlement, we export and delete copies we hold.

Compliance

OWASP-minded web development. Systems designed to align with the Kenya Data Protection Act 2019 and sector rules you specify in scope.

Incidents

Contain, investigate, notify affected parties within 72 hours where required, then remediate. Written playbooks, not improvisation.
